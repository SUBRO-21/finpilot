FinPilot - dependency vulnerabilities to fix later
(from `npm audit`, 2026-11-15: 6 vulnerabilities, 1 moderate / 5 high, from 3 root causes)

1. zod 3.25.76  -- HIGH, FIX FIRST
   Issue:  Memory exhaustion when validating oversized constrained collections
           (arrays/sets with .max() etc.). https://github.com/advisories/GHSA-mrhx-c7xc-m3w5
   Risk:   Real. The API validates user request bodies with zod, and express.json
           accepts bodies up to 5 MB (apps/api/src/index.ts:13). A huge array in a
           request could slow down or crash the API.
   Fix:    - Upgrade to zod@4.6.7 or newer (major version; check the zod usages
             in the 4 files under apps/api/src that import zod).
           - Lower the express.json limit from 5mb to what the largest real request
             (statement upload) actually needs.

2. deepmerge-ts 7.1.5  -- HIGH (also flags @prisma/config and prisma)
   Issue:  Stack exhaustion when merging recursive object graphs.
           https://github.com/advisories/GHSA-ggr8-5vv4-36mx
   Risk:   Practically none. Only the Prisma CLI loads it to read its own config;
           it never handles user data.
   Fix:    `npm audit fix` (non-breaking).
